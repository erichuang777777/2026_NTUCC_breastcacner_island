# 希望島角色模型 v02

六份 GLB 與網頁使用相同幾何、材質與階層，來源為 `../../hope-characters.js`。

| 檔案 | 造型 |
|---|---|
| hope-visitor-v02.glb | 日常服島民 |
| hope-scarf-v02.glb | 玫瑰頭巾與肩包 |
| hope-doctor-v02.glb | 深灰醫師工作服與聽診器 |
| hope-nurse-v02.glb | 深藍護理服與識別證 |
| hope-surgeon-v02.glb | 綠色刷手服與帽子 |
| hope-scrub-v02.glb | 綠色刷手服、帽子與口罩 |

角色前方為 +Z，地面為 Y=0。頭、身體、雙臂與雙腿有獨立具名節點。GLB 可匯入 Blender 繼續編修；目前不是蒙皮骨架模型，也未內含動畫片段。網頁以節點旋轉播放走路動作。

2026-11-05 精修：增加眼白、虹膜、瞳孔與高光、耳內、髮束、袖口、鞋底與鞋帶、識別證與口袋細節。v01 保留作版本追溯。
