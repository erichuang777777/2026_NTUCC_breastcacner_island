Agent 衛教文章 API

管理頁 → Agent API → 建立專用金鑰。將金鑰交給需要維護文章的 Agent；每把金鑰可獨立撤銷，不能操作活動或管理設定。

下載 OpenAPI 規格 · 下載文章 JSON 範例

文章只需四個內容欄位

欄位用途
title標題，最多 160 字元。
category類別名稱或數字 ID；可用 GET /api/agent/categories 查詢。
body內文，最多 100,000 字元，保留換行。
references參考資料，最多 10,000 字元，來源名稱或網址，每筆一行。

POST 新增

將金鑰放在環境變數 HOPE_API_KEY，把文章存成 article.json。

成功回傳 HTTP 201，包含文章 id 與 version。預設儲存草稿；若內容已確認可發布，額外加入 "publish": true。
POST 更新
先 GET /api/agent/articles/{id} 取得最新版本；更新 JSON 包含同樣四個欄位與最新的 version。
更新預設儲存草稿，保留原本線上版本；加入 "publish": true 才會更新病人看到的內容。成功回傳 HTTP 200 與新的版本。回傳 409 代表版本衝突，請重新讀取並合併變更。
避免重複建立
同一筆寫入與重試使用相同的 Idempotency-Key；同一把金鑰、相同路徑和內容會回傳第一次的結果，不重複新增。下一筆不同寫入請使用新的 Idempotency-Key。同一個值搭配不同內容會回傳 409。
查詢與錯誤
GET /api/agent/categories
GET /api/agent/articles
GET /api/agent/articles/{id}

Authorization: Bearer <API 金鑰>

400：欄位錯誤　401：金鑰無效或已撤銷
404：找不到文章　409：版本或重送識別衝突
413：內容過大　415：請使用 application/json
Agent API 使用 Bearer 金鑰，不需要登入 Cookie 或 Origin 標頭。管理介面仍使用管理密碼。不要將金鑰放進網址、公開網頁或版本庫。
之後部署到 Netlify
串接時將網站位址放在設定中，保留 /api/agent/* 路徑與本規格。這份 API 目前由本機 Python 共用服務提供；Netlify 雲端後端與持久資料庫移轉仍屬部署階段工作，不能只上傳靜態資料夾就取代目前服務。
