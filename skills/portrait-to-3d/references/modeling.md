# 量測與立體捏臉

| 現象 | 判讀方法 | 修正方向 |
| --- | --- | --- |
| 正面不像但紋理很真 | 固定尺度，素模與照片標點比較 | 頭寬、眼距、鼻口下巴位置，先不加毛孔 |
| 側面像面具 | 左右 90° 看眼眶、顴骨、嘴部與後腦 | 恢復深度，避免整張臉變成平面 |
| 下巴像斷開 | 同角度切換素模／完整材質 | 素模也有問題才修網格；否則先查貼圖 |
| 五官轉動後漂移 | 旋轉檢查眼球、眉毛與臉面距離 | 使用曲面或實體幾何，不用朝相機貼片 |
| 側面突然凹凸 | 比較法線、位移與前版 | 降低變形、加寬過渡，保留骨點 |

## 底模與來源

優先使用已有且可編輯的解剖底模。新增底模需記錄授權、來源、版本、雜湊；希望之島的 MakeHuman 核心素材有 CC0 紀錄，但第三方服裝／髮型不可直接套用。不要將特定人的完成頭部當成所有人的預設底模。

至少具備額頭、顱骨、眼眶、鼻翼、唇厚、下顎、耳朵與頸部連續性。需要表情時保留口腔與眼瞼拓撲；靜態胸像不必順便加入動畫系統。

## 照片對位

記錄照片尺寸、頭部框、眼睛與下巴位置、相機投影、角度、目標點及尺度。配合照片視角，不拉伸照片遷就模型。正交比對適合量測；透視照片的鼻耳比例可能仍需透視相機校準。

MediaPipe 只協助找參考點。頭髮、皺紋、鬍鬚及遮擋需另外觀察；偵測點應人工核對。單張照片的偵測 z 不是毫米或掃描深度。失敗時可手動標點，不生成替代原照。

使用同座標系的對應點，逐區處理比例與五官。投影位移保留深度並在側臉、後腦與下頸平順衰減。TPS／RBF 須加入固定點，避免後腦跟著偏移。眼眶變形後同步檢查眼球與眼瞼。

## 局部工具

`blender_portrait.py edit` 接受物件局部座標與既有頂點群組。`handles` 對量測後的位移加距離衰減；`relax` 在指定權重內做鄰點平滑。兩者限制相對基準的最大位移。參數依模型單位決定，案例的 0.006 不是通用值，也不是毫米。

先檢查物件座標／縮放，變形後比較應保留部位、開放邊界、退化面、非流形邊及面片方向。工具不保證無自交或可動畫，依交付用途另外檢查。

髮片與局部眼球面片可能本來就有開放邊；完整頭頸若新增裂縫則是回歸。保留可編輯基準，在匯出副本做必要三角化；法線烘焙與匯出使用相同劃分。
