# 頭髮、照片投影與皮膚連續性

## 皮膚

- 原照不可變；亮度、背景污染與陰影補償只發生在衍生材質。
- 照片映射至完整曲面，再烘焙 PBR 貼圖。正面保留本人紋理，側臉、耳後、下巴與頸部延伸連續膚色及法線；推估程序紋理不是本人真實側面。
- 漸變同時考慮照片臉部邊界、曲面方向、深度與遮擋。不能讓背景、衣服或下巴陰影拖到頸部，也不能突然切回純色。
- 查證取樣數值的色彩空間。緩衝區是否已線性化受載入方式影響，不能一律對 `image.pixels` 再做 sRGB 轉換；用已知色值與輸出核對。基底色通常為 sRGB，法線為 Non-Color。
- 照片光影與 3D 燈光疊加可能使唇線／下顎過黑。分辨原照陰影、實體凹陷或接縫再處理，不靠全場提亮掩蓋結構。

## 頭髮

先比對外輪廓、分線、兩側高度及髮色，再補髮束。髮根接頭皮、髮梢形成外輪廓；只擴大髮殼會留下懸空。

以頭部 BVH 最近點逐根檢查根部，記錄最大／平均距離與模型單位，不能只測導引面。耳後插值可能跨空隙，需重投影實際根部。用細髮與透明過渡取代實心髮帶；確認正面未長出規整的一整排短毛。不要縮小整個髮殼破壞已認可外形。

側視檢查厚度與受光。透明髮片在 WebGL 有排序與雙面成本，需驗證 alpha 與頂點色，不只看 Blender。

## 斷線排查

1. 同角度看素模；仍有線時查裂縫、重疊、退化面、法線及折角。
2. 暫移除法線貼圖；消失才優先查切線、UV 集、法線通道與色彩空間。
3. 若仍有線，換均勻基底色，查照片遮罩、UV 重疊、烘焙空白像素及 mip 邊緣。
4. 同一份三角化網格與 UV 做烘焙和匯出，明確對應 normal map UV 與切線。
5. UV 島保留間隔、增加烘焙外擴，未烘焙區可用膚色／中性法線底色避免黑縫。希望之島以 24 px／EXTEND 改善，但需依尺寸與縮圖實測，不是通用規格。
6. 回網頁檢查近景、原尺度及遠距縮圖。診斷時移除法線的中間版不能誤當最終模型。

生成的 2D 影像不算已完成 3D。生成材質須標記合成部位，仍需旋轉檢查。
