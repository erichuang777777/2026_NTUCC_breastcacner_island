# 臺大癌醫・希望之島

目前版本：v22（2026-11-12）。同一個十島 3D 場景，提供院區主視角、臺灣全景、居民模擬、衛教閱讀、當日活動及願望星空。

## 啟動與入口

```bash
cd webgl-prototype
HOPE_ALLOWED_HOSTS=192.168.1.100 python3 hope-server.py --host 0.0.0.0 --port 8001
```

- 互動地圖：http://127.0.0.1:8001/taiwan-study.html
- 大螢幕投影：http://127.0.0.1:8001/island-projection.html
- 衛教／活動管理：http://127.0.0.1:8001/education-admin.html
- 病人活動入口：http://127.0.0.1:8001/event-join.html
- 角色設定：http://127.0.0.1:8001/resident-setup.html
- 手機搖桿：http://192.168.1.100:8001/mobile-controller.html
- Agent API 說明：http://127.0.0.1:8001/agent-api.html

各頁右下角「功能選單」可切換頁面。地圖的鏡頭、衛教、許願、角色與居民控制也收在選單中；閒置 8 秒會收起，操作輸入欄位時保持開啟。投影使用獨立頁面，管理頁另開分頁。

請用上述共用服務，單純的靜態伺服器不提供文章、附件或活動 API。Three.js 仍從 jsDelivr 載入，首次載入需要網路。

## 第一次使用管理頁

正式資料庫已依使用者指定更新管理密碼，舊管理工作階段已失效。密碼長度為 8 至 128 字元；系統儲存加鹽 PBKDF2 雜湊，不儲存明文密碼。新建空白資料庫仍需在本機首次設定。

既有 30 篇示範單元已匯入草稿，沒有自動發布為醫療衛教。編輯介面只需「標題、類別、內文、參考資料」四欄；舊文章的摘要、作者、審閱者等資料仍保留，簡化編輯不會刪除這些資料。PDF、DOCX、JPG、PNG 附件每份最多 12 MB，需符合實際檔案格式。Word 以原檔附件提供，不進行自動全文轉換。附件更換可先移除舊附件、加入新檔後儲存。

草稿儲存、發布、下架與版本還原彼此分開。修改已發布文章不會立刻改動病人端；必須再次發布。發布前需有內文或附件，不再要求額外填寫審閱者欄位。版本還原先成為草稿。患者只讀得到已發布文章及其附件；管理者可預覽草稿附件。

## 當日活動

1. 管理頁切到「當日活動」，輸入名稱與活動日期。
2. 建立後直接顯示專屬入口 QR Code，可放大展示或下載 SVG；確認入口網址為手機可到達的位址。
3. 病人掃描後進入該活動的角色設定頁，選擇 3D 角色、髮型、膚色、頭髮／配件、上衣與褲裝顏色，再加入並開啟手機搖桿；可切到衛教闖關。
4. 逐題回答三個理解問題；答錯可重試，三題全對才通關。
5. 管理頁可更新參加與通關人數、結束或重新開放活動。

日期依 Asia/Taipei 判定，只接受當天且開放中的活動。活動題目在建立時留存快照，不因後續文章編輯改動答案。答案與進度由伺服器驗證；重新整理同一分頁可接續，切換活動／下一位參加者會清除此裝置工作階段的存取權。個人進度仍保留在資料庫。

手機每約 150 ms 提交方向，投影每 250 ms 讀取共用位置；畫面使用平滑移動。每位參加者只能控制自己的角色，伺服器限制速度、可走區域與其他受控角色的間距。重送同一移動序號不會重複移動；手機放開、失去焦點或切換頁面即停止，90 秒未連線後釋出名額。

目前七個手機操控名額搭配五位電影人物，最多十二位移動島民；院長是入口旁的定點人物，不占操控名額。額滿時顯示等待訊息，仍可參加衛教闖關。活動參加者的位置跨投影畫面同步；背景居民仍在各畫面模擬，其動線不是病人的實際院內動線，也不計入病人闖關成果。桌面 WASD 自由探索角色仍屬該頁的體驗，手機則以活動身分綁定專屬角色。


地圖內的三題練習為自由體驗；正式活動進度請從活動 QR Code 加入。一般參加入口也可選擇今日開放活動，不需輸入代碼。重送相同加入請求不會重複建立島民；進度存取憑證只保存在該分頁工作階段，不放入 QR 或網址。

本次區域網路位址為 `http://192.168.1.100:8001`，手機與展示電腦須連到可互通的同一個網路。IP 變更後，請更新啟動指令的 `HOPE_ALLOWED_HOSTS` 及管理頁的「手機參加入口網址」，並重新下載 QR。省略 `--host` 時仍只接受本機連線。可用 `HOPE_PUBLIC_URL` 指定院內正式入口；它優先於管理頁設定。此次沒有建立網際網路公開網址或 HTTPS。

- `visual-references/`：最初美術、角色、建築參考，保留原處。
- `component-system/`：可編輯模型、建模腳本與元件定義，保留原處。

願望星空目前仍使用既有瀏覽器儲存機制；此次共用資料與活動功能不代表願望已跨裝置同步。

## v22 Agent API 與手機控制

管理頁的「Agent API」可建立、查看金鑰名稱與撤銷金鑰；明文只顯示一次，資料庫只保存雜湊。Agent 使用 Authorization: Bearer，不必使用管理 Cookie 或 Origin。支援 GET 類別／文章、POST 新增及 POST 更新；更新需要版本，Idempotency-Key 可避免重送造成重複文章。完整契約見 `webgl-prototype/agent-openapi.json` 與 `agent-api.html`。

登入管理頁後建立活動 QR；手機掃描 → 原定稿角色設定 → 搖桿控制自己的島民 → 切換衛教闖關。手機控制頁不載入 Three.js 或整座島嶼模型。API 回傳的共用位置可由多個投影頁同時顯示。

院門口新增吳耀銘院長的專屬立體角色，灰白短髮、白袍及深色領帶；參考與授權背景記錄在 `art-source/director-wu/SOURCE.md`。現使用 director-v02，依肖像調整五官與髮型，依使用者要求不顯示姓名看板。角色位於入口左側 [2.2, 1.6]，保留正門通道，提供迎賓招手；「功能選單 → 院長迎賓」可近看。

Netlify 部署規劃見 `specifications/netlify-v22-deployment-plan.md`。目前仍為本機服務，尚未完成 Netlify 雲端 API／Postgres 移植或對外部署，不可只部署 dist 就視為所有功能已上線。

共用可走區域：`webgl-prototype/server-assets/walkable-v22.json`。它由實際場景碰撞資料取樣產生；若改變地形、建物或障礙物，需一併重新產生並驗證，避免伺服器與場景碰撞資料不同步。
