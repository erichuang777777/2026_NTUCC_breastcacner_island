# 乳癌希望之島｜元件製作套件 v0.1

本套件建立可重複的 3D 元件製作流程。第一個樣板元件為 `CHR-VISITOR-001` 島民訪客角色，包含多角度設定圖、元件 metadata 範本與製作/驗收流程。

## 目前元件

- `CHR-VISITOR-001`：島民角色共用比例樣板與六角度圖。
- `CHR-ROLE-MATRIX-001`：男女外觀呈現與病友、醫師、護理師、手術室刷手服裝矩陣。
- `BLD-NTUCC-001`：以院方外觀照片為參照的中心地標概念。
- `BLD-DEPARTMENT-001`：六種科室共用小屋母型概念。
- `ENV-PATHOLOGY-ISLAND-001`：病理診斷島灰模尺度、錨點與北側拼接接口。
- `ENV-TAIWAN-ARCHIPELAGO-001`：多座照護小島共同構成的臺灣輪廓全景。
- `BLD-HOPE-LIGHTHOUSE-001`：中央聚光燈塔與日夜光束規格。
- `ENV-WISH-SKY-001`：匿名願望星群與完成流星效果。
- `UI-AVATAR-BUILDER-001`：本機照片預覽與角色服裝選擇介面規格。
- `UI-AVATAR-BUILDER-001`：本機照片預覽與角色服裝選擇原型。

## 新增元件

1. 複製 `assets/_template/`，以新 ID 建立資料夾。
2. 填寫 `component.yaml`，鎖定功能、比例、配色、視角、互動與效能預算。
3. 按 `docs/production-pipeline.md` 完成概念圖、模型、匯出、預覽和驗收。
4. 只有通過檢核的 GLB 才能進入網站；原始 `.blend` 和概念圖保留在來源資料夾。

角色用共用骨架與服裝變體建立；照片上傳原型僅在瀏覽器本機預覽。正式線上臉部處理須另行通過院方個資及資安審查。

## ID 命名

- `CHR-...` 角色
- `BLD-...` 建築
- `ENV-...` 島嶼、地形、六角區
- `PROP-...` 家具、植物、路燈、標誌等場景物件
- `UI-...` 網頁介面圖像或動態元件

ID 建立後不隨名稱或顏色變更；以版本號記錄修改。醫療衛教文字與 3D 資產分開管理。
