# 大頭照建立島民角色｜原型規格

## 原型功能

- 使用者選擇女性／男性外觀呈現及病友／訪客、醫師、護理師、手術室刷手四種服裝。
- 使用者可從裝置選取 JPG、PNG 或 WebP 大頭照，瀏覽器以裁切後照片覆蓋角色頭部示意區。
- 照片只在目前分頁記憶體中處理，不寫入伺服器、資料庫、Cookie 或 localStorage；關閉頁面即清除。可隨時按「清除照片」。
- 第一版不自動辨識身分、不做人臉特徵分析、不生成真正 3D 網格或 AI 臉部。現在的操作只驗證角色選擇與照片裁切體驗。

## 正式 3D 版本建議

1. 維持可選擇的匿名角色外觀；上傳前清楚顯示用途、保存方式、刪除時點和同意選項。
2. 優先在裝置本機將照片轉為簡化臉部貼圖，並由使用者確認後套用到共用角色骨架；若需雲端 AI 處理，另行取得明確同意並完成院方個資／資安評估。
3. 不把原始照片或臉部特徵寫入活動分析；不將上傳照片展示在公共大螢幕，除非使用者另外明確選擇分享。
4. 明確提供跳過、重設、刪除、預覽和離島後清除功能；匿名訪客不必登入。
5. 先確認上傳者有權使用照片；避免未成年者或第三人的照片進入公共活動畫面。

此文件為產品原型規格，不構成院方隱私或資安核准。
