# 原始海報拆解與燈塔本體試作

來源：專案根目錄 `2fd48225-1174-4fde-99ec-6e9a33b06ae5.png`，使用者提供。後續生成的群島主視覺不取代這張來源。

## 畫面拆解

1. 主地標：漸縮奶油色燈塔、粉紅立體交叉緞帶、陽台欄杆、玻璃燈室、粉紅圓頂。
2. 地形：上層燈塔平台、下層花園平台、多面岩壁、中央長階梯。
3. 建築與設施：兩座暖光小屋、環形石徑、木欄杆、長椅、雙側碼頭與帆船。
4. 植栽：櫻花樹、常綠樹、喬木、多層花叢與草皮。
5. 氣氛：夕陽至夜空的過渡、海面反射、燈塔光束、希望星軌。
6. 敘事：散步與坐在長椅上的人物，底部許願至願望完成的示意。

## 本次唯一製作範圍

燈塔本體，輸出 `export/poster-lighthouse-tower-v01.blend`、同名 GLB 與 PNG。保留既有網頁模型，先交付獨立造型供檢視。

## 檢視標準

- 保留漸縮塔身、暖米白與粉紅配色、正面入口及立體交叉緞帶。
- 燈室有獨立玻璃、窗框、光源；陽台有獨立立柱與雙層扶手。
- 模型可轉動檢視，不是海報平面貼圖。
- 三角面數與載入成功不代表美術驗收完成。

## 待確認與限制

目前為第一個造型試作，尚未經使用者美術驗收。海報只有單一角度，背面及精確尺寸是推定；塔頂比例、塔身表面細節與海報光束仍可精修。本次未製作地形、花園、人物，也未更換網頁既有燈塔。
