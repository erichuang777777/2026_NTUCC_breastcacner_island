# 網頁 3D 與微電影整合流程

日期：2026-11-11。狀態：已決議的流程；各階段尚未完成。

## 決議

- **網頁**以 3D 即時渲染為主，資產由 Blender 建模後匯出 GLB。
- **微電影**維持 MiniMax H3 生成 AI 影片（ComfyUI 生成、HyperFrames 後製），不改為 3D 渲染，不使用 GLB。
- 兩者的整合以**外觀一致**為目標：互相提供參考圖，並以對照表記錄每個角色與場景的對應來源。
- 以 11/05 決議為準：可愛立體風格、十座不規則拼圖島嶼、岸邊直接相接、不設橋樑。

## 整合方式

### 電影 → 網頁
微電影的 `assets/interactive-web-reference-pack/` 是給網頁的參考包：
- 角色身份：女主角 `characters/hero/ho_front.png` 為臉部主參考，`stage_*` 為不同時期的頭巾、髮型與服裝；配角（阿澤、林醫師、王醫師、陳護理師、年輕病友）見 `characters/supporting/`。
- 第五幕島嶼與燈塔：`island-lighthouse/storyboard_*` 為採用的分鏡；`concept_A／B／C` 為**尚未定稿**的美術方向，不可自行選定。

網頁 3D 角色與島嶼、燈塔以這些參考圖為外觀依據。

### 網頁 → 電影
Codex 從 Blender 以固定鏡位輸出網頁島嶼、燈塔、醫院的渲染圖，提供給微電影作為第五幕 H3 關鍵影格的候選。是否採用由微電影與使用者決定。

### 對照表
`scene/film-references.json` 記錄每個網頁資產或角色對應的電影參考圖，以及網頁輸出給電影的渲染圖。

## 共用資料（網頁與 Blender 使用）

| 檔案 | 內容 |
|---|---|
| `scene/shots.json` | 網頁驗收與參考渲染鏡位：相機位置、目標、垂直視角、畫面比例、日夜 |
| `scene/lighting.json` | 光線預設：白天、黃昏、夜間；色彩管理與曝光 |
| `scene/assets.json` | 資產登記：ID、版本、GLB 路徑、LOD、來源（Blender 或程式產生） |
| `scene/film-references.json` | 網頁與電影的參考圖對照 |

座標以網頁（Three.js、glTF）為準：Y 軸朝上。Blender 為 Z 軸朝上，glTF 匯入時自動轉換：Blender `(x, y, z)` 對應網頁 `(x, -z, y)`。

## 已知的技術障礙

1. **程序式模型**：島嶼地形、十科小屋、花園、道具多由 JS 即時產生（`hope-landscapes.js`、`taiwan-layout.js`、`hope-environment.js`、`hope-landmark-gardens.js`），Blender 無法直接使用，也就無法渲染參考圖。
   - 過渡：用 Three.js `GLTFExporter` 匯出目前場景，交給 Blender 作為配置基準。
   - 正式：逐步改為 Blender 建模的 GLB。海岸線、島嶼分區與碰撞仍保留為資料。
2. **色彩管理不一致**：網頁使用 `ACESFilmicToneMapping`，Blender 預設 AgX。網頁的 Three.js 0.160.0 已支援 `AgXToneMapping`，兩邊統一用 AgX，參考渲染圖才會與網頁一致。
3. **大型檔案不進 git**：GLB 與 `.blend` 約 3 GB，本機未安裝 Git LFS，以 `.gitignore` 排除；版本以檔名 `vNN` 與 `scene/assets.json` 登記。

## 人物規則

- 網頁角色共用同一套骨架（目前 18 根）與動作（idle、walk、wave、read）。
- 有電影對應的角色（例如女主角各時期、醫護配角），外觀以電影的身份參考圖為準：臉型、髮型或頭巾、服裝主色。
- 醫師（深灰）、護理（深藍）、刷手（綠）在全景尺寸也要能以主色與輪廓分辨。

## 島卡

每座島一張 16:9 島卡：地標、三件必備道具、岸線層次、入口位置、科別意象。先完成病理島作為樣板。key art 有而網頁缺的元素優先補齊：分層岩岸、浪花、木棧道、路燈與長椅群、窗光。

## 審查關卡（每階段）

1. 同鏡位並排：key art 或電影參考圖、網頁截圖、Blender 渲染，存於 `reviews/`。
2. 輪廓測試：全景尺寸下，十島、角色、燈塔與醫院仍可分辨。
3. 新資產已登記在 `scene/assets.json`；有電影對應者登記在 `scene/film-references.json`。
4. 碰撞與尋路測試通過。
