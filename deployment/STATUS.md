## 資料與驗證界線

依使用者決定，新站獨立開始。舊 SQLite、2 個角色、1 場活動與 1 位參加者保留本機，未匯入雲端。原管理密碼以雜湊設定，未提交 GitHub；正式資料庫維持 CLI 唯讀保護。雲端初始 30 篇示範文章仍為草稿，需於管理頁確認後發布。

單一裝置雲端 API 測試中位耗時約 362 ms，控制請求約 351–373 ms。這不是現場多人負載或實際手機電信網路測試。手機前端保留預測，正式活動仍應以實機驗證延遲、GPU 效能及七人同時操控；規模擴大時考慮持久即時訊息服務。

早期 CLI 手動 draft deploy 未取得資料庫環境；正式站已改由連接 GitHub 的 Netlify 建置流程部署並驗證成功。後續請使用 Git 推送與 Netlify 建置流程，不把單純上傳靜態 public 目錄視為完整後端部署。
